# Settings icons

Source: [Lucide 0.468.0](https://github.com/lucide-icons/lucide/tree/0.468.0/icons).
The upstream ISC license is preserved in `LICENSE`.

The link, sliders-horizontal, book-open, lock-keyhole, app-window and chevron-down
icons are rasterized from upstream SVGs, with stroke color `#537875`. Most source
rasters are 192 px; the app-window illustration is 256 px with a lighter stroke.
Swing scales these assets to the control size; no build-time npm dependency is required.

These are interface illustrations, not OpenAI logos. Text and controls remain native
Swing components and are not baked into screenshots.
